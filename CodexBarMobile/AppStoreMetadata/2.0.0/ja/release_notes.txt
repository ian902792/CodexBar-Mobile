CodexBar 2.0 は iOS 27 と iPadOS 27 に対応し、データアーキテクチャを全面的に刷新しました。履歴の読み込み、Mac 間の同期、画面の切り替えが従来より大幅に高速になりました。

• 再構築したデータパイプラインにより、複数の Mac の使用量をより速く読み込み、統合、更新します。履歴の欠落と実際のゼロは引き続き区別されます。
• Token Activity ヒートマップで日ごとの Token 合計をひと目で確認できます。詳細ではすべての Provider を表示し、日付をタップまたは長押しして、最大 1 年分の履歴を確認できます。
• 新しい iPad 体験では、広い画面を活かした並列表示と使い慣れた下部タブを両立しました。
• 共有機能を全面刷新しました。プレビュー中心のエディタ、新しい Classic と Vibe、Heatmap カードを利用できます。
