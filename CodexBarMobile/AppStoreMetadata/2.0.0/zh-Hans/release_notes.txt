CodexBar 2.0 正式支持 iOS 27 与 iPadOS 27，并带来全新的数据架构。历史加载、跨 Mac 同步和页面切换相比旧版本大幅提速。

• 重构后的数据管线能更快加载、合并和刷新多台 Mac 的用量，同时继续区分缺失历史与真实零用量。
• Token Activity 热力图让每日 Token 总量一目了然。点开即可查看全部 Provider，点按或长按任意日期，并回溯最多一年的历史。
• 全新的 iPad 体验充分利用宽屏并排展示，同时保留熟悉的底部标签栏。
• 分享功能全面焕新：预览优先的编辑器、重新设计的 Classic 与 Vibe 卡片，以及全新的 Heatmap 卡片。
